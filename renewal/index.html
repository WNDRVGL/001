01

About

好奇心のままに、
どこまでも渡っていく。

「Wandervogel（ワンダーフォーゲル）」は、渡り鳥を意味するドイツ語。 私たちはその名に、驚き（Wonder）を求めて領域を越えていく姿勢を込めました。

事業や商品、サービス、まち。あらゆるものの価値の根っこには、その存在理由＝「魂」があります。 WONDERVOGELは、まずその魂を言葉にするコンセプトメイクから伴走し、 戦略・企画・制作・運用までを一気通貫で手がけます。

案件ごとに、デザイナー、映像ディレクター、カメラマン、エンジニアなど 多様なクリエイターのネットワークから最適なチームを編成。 仙台・東北、そして東京のクライアントとともに、新しい価値をつくっています。

  1. 0 → 1魂をつくる課題整理 / コンセプトメイク / 戦略立案
  2. 1 → 10表現にする企画 / コピー / デザイン / 映像
  3. 10 → 100届けきるメディア展開 / イベント / 運用・改善

04

Profile

H.S

代表取締役 / クリエイティブディレクター / コピーライター

佐藤 浩幸Hiroyuki Sato

学生時代からテレビ番組の企画・制作・撮影などの技術に携わる。 卒業後、フリーランスとして企画・デザインを手がけたのち、 イベントプロデュースを中心とするプロダクションのクリエイティブ部門に所属。 2020年、株式会社WONDERVOGELを設立。

プランニングとコピーライティングを武器に、事業のコンセプトメイクから 広告・Web・映像・イベントまで、「企画と言葉と表現」で全工程をワンストップで手がける。
